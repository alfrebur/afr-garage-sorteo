# AFR Garage Sorteo

Landing del sorteo de AFR Garage: packs, cuenta regresiva y formulario de compra.

## Estructura

- `index.html` — página
- `styles.css` — estilos
- `script.js` — cuenta regresiva, selección de pack y checkout (solo frente, todavía no envía pedidos)
- `assets/` — logo y foto del premio

## Ver en local

Abrir `index.html` en el navegador, o:

```
python3 -m http.server 8000
```
